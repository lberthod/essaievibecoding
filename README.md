# Essai Vebe Coding

This repository contains the files for the Essai Vebe Coding project.

## Files

- `index.html` - Main HTML file
- `novembre2.html` - Additional HTML page
- `style.css` - CSS styling
- `script.js` - JavaScript functionality
- `export.mp4` - Video export file

## Setup

To run this project locally:
1. Open `index.html` in a web browser
2. The project should work out of the box with no additional setup required

## Project Structure

The project is structured as a simple web application with HTML, CSS, and JavaScript components.
